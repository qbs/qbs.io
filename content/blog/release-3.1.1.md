The [Qbs build tool](http://qbs.io) version 3.1.1 is available.

## What's new

<!--more-->

This is a minor bugfix release that contains the following fix:

* Modules support now properly handles absolute paths in the files pointing to the std modules.

Sources, binaries, etc can be found [here](https://download.qt.io/official_releases/qbs/3.1.1/).

Also, Qbs binaries are available via different package managers such as
[Chocolatey](https://community.chocolatey.org/packages/qbs),
[Brew](https://formulae.brew.sh/formula/qbs), [macports](https://ports.macports.org/port/qbs/) and
[others](https://repology.org/metapackage/qbs/versions).
