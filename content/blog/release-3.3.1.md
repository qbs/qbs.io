The [Qbs build tool](http://qbs.io) version 3.3.1 is available.

## What's new

<!--more-->

This is a minor bugfix release that contains several fixes:

* Fixed reading integer values from profiles.
* The build configuration name `profiling` now maps to the `profiling` build variant
  by default.
* Fixed lookup of the metatypes files for Qt versions before 6.5.

Sources, binaries, etc can be found [here](https://download.qt.io/official_releases/qbs/3.3.1/).

Also, Qbs binaries are available via different package managers such as
[Chocolatey](https://community.chocolatey.org/packages/qbs),
[Brew](https://formulae.brew.sh/formula/qbs), [macports](https://ports.macports.org/port/qbs/) and
[others](https://repology.org/metapackage/qbs/versions).
